# Create Readme

Create a README.md file accordings to the template at `./assets/template.md`.

For this you should:

1. Inspect the code base and figure out
   - What this repository is about
   - What technologies are used
   - How the project gets built
   - How the project can be deployed
     - If there are any environment variables necessary
   - Any information necessary to develop
   - What the license is (if there is any)
1. Write down that information in a scratchpad, if you have any
1. Write the `README.md` according to the provided template step by step
1. When writing down commands, test if they exist and succeed
1. Add any badges you think make sense

## Examples

Examples of good `README.md` files can be found at `./references`. Take a look at them and copy the style.
